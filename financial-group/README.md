# Financial Group

Aplicación web de ahorro grupal e individual (HTML, CSS y JavaScript, sin dependencias).

## Ejecutar
En VS Code: extensión **Live Server** > clic derecho en `index.html` > *Open with Live Server*.

## Estructura
- `index.html` landing · `login.html` acceso/registro
- `home`, `metas`, `meta`, `aporte`, `alertas`, `perfil` (.html): pantallas de la app
- `css/styles.css` estilos · `js/app.js` lógica y datos (localStorage)

Los datos se guardan en el navegador; para reiniciar, borra el localStorage del sitio.
